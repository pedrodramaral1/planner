# Planner

Planner pessoal — trabalho, estudos, financeiro e protocolos em um só lugar.

100% client-side: HTML + CSS + JavaScript puro, dados salvos no `localStorage` do navegador. Sem backend, sem dependências.

## Seções

- **Hoje** — resumo do dia: tarefas pendentes, progresso de estudo da semana, saldo do mês e protocolos.
- **Trabalho** — kanban de tarefas (a fazer / fazendo / feito) com prioridade e prazo.
- **Estudos** — registro de sessões de estudo com meta semanal de minutos e breakdown por matéria.
- **Financeiro** — receitas e gastos por mês, com categorias e saldo.
- **Protocolos** — checklists reutilizáveis para rotinas que se repetem (com reset).

## Uso

Abra `index.html` no navegador. Pronto.

Backup: botão **Exportar dados** gera um JSON; **Importar dados** restaura.
